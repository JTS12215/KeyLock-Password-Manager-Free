# Contributing to KeyLock

### ⚠️ NOTICE: CONTRIBUTIONS ARE NO LONGER ACCEPTED

Thank you for your interest in contributing to KeyLock Password Manager! 

Please be advised that KeyLock Free Legacy Edition (V26.02.6.3) has been officially moved into a **legacy/archived state**. As a result, this repository is now **Read-Only**:
* We are no longer accepting new feature requests, bug fixes, or enhancements.
* Pull Requests (PRs) and Issues have been closed and will not be reviewed.

---

## What You Can Do (Under the GPLv3)

While this specific repository is frozen, KeyLock remains an open-source project under the **GNU General Public License v3.0**. Under the terms of this license, you still retain the freedom to:

1. **Fork the Project:** You are welcome to fork this repository to your own GitHub account to continue independent development, fix bugs for your own deployment, or adapt the code for your personal use.
2. **Redistribute:** You may share your modified versions, provided that your derived project remains entirely open-source under the exact same GPLv3 license terms.
3. **Inspect the Code:** The codebase remains completely transparent for anyone wishing to review our encryption methods or local-first architecture implementation.

*Note: Please respect the Trademark Notice outlined in the README.md if you choose to distribute a modified fork.*

---

## Security Vulnerabilities
If you discover a critical security vulnerability within this legacy code, please do not disclose it publicly. For archival safety records, you may still report it privately via email to **keylock.app@gmail.com**, though please note that active patches are no longer guaranteed for this version.
